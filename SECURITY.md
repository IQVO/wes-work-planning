# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for a suspected vulnerability. Report it
privately through [GitHub Security Advisories](https://github.com/claudioed/wes-work-planning/security/advisories/new).

Include a clear description, affected version or commit, reproduction steps,
impact, and—if known—a suggested remediation. You will receive an acknowledgement
within 7 days and a status update at least every 14 days until resolution.

## Supported versions

Security fixes are applied to the current `develop` branch and released from
`main`. Please test the latest supported release or `develop` before reporting
an issue when practical.

## Disclosure

Please allow time for a fix and coordinated release before public disclosure.
We will credit reporters in the advisory unless they prefer to remain anonymous.
